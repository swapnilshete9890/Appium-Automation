# Appium Mobile Automation Framework

Android automation framework built using Appium, Java, and TestNG
covering native app testing, advanced gestures, and mobile browser automation.

## Tech Stack
Appium | Java | TestNG | Maven | UIAutomator2 | Git

## Apps Tested
- Calculator — functional UI automation
- Phone Dialer — native app interaction
- General Store — form inputs, checkboxes, radio buttons
- ApiDemos — gestures, drag & drop, drawing gestures

## What's Covered

Day 1 — APK installation, Calculator automation
Day 2 — Phone Dialer, Checkbox, Radio Button, Text input
Day 3 — Drag & Drop (W3C), Dropdown, Scroll, Switches
Day 4 — App Management, Swipe & Scroll on long pages
Day 5 — Mobile Chrome browser automation, Long Press
Day 6 — Drawing & Signature gestures

## Setup Requirements
- Android Studio Emulator (Android 10+)
- Appium Server 2.x
- Java 11+
- Maven
